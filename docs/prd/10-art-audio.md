# 10 · 美术、音效与内容生产

> 响应验收区分应用内输入事件→首次提交形变（目标≤1渲染帧）与物理触摸→屏幕显示的端到端延迟；后者单独测量，不直接套用16.7ms。两周范围以第14章为准。

> Codex负责资产与视觉审核，Claude负责Shader、形变、导入和工具；批次、文件规范、锚点与交付记录见[美术交付合同](../production/art.md)。本章清单不代表资产已经完成。

## 10.1 风格要求（可验收的描述）

| 项 | 要求 |
|---|---|
| 造型 | 史莱姆为圆润水滴/团子轮廓，底部略扁平；无四肢；眼睛占身体高度 18%～24% |
| 线条 | 描边 = 身体暗部色再加深 25%，2～3px（@1x 256px 身体），不用纯黑 |
| 光照 | 统一左上 45° 主光；高光为两层（大柔光+小硬光）；底部接触阴影 |
| 材质区分 | Sugar 半透明（可见背景轻微折射）；Cream 不透明哑光；Strawberry 果冻光泽；Lemon 微颗粒；Cocoa 厚重低光泽 |
| 可读性 | 64px 缩略图下，主体色、花纹形状、头饰三者都可辨认；色弱模拟（Deuteranopia/Protanopia）下花纹形状仍能区分品种 |
| 情绪 | 表情只用眼和嘴，12 组覆盖全部情绪（见 10.2） |

## 10.3 模块化生产方案

```
品种外观 = 身体底图 × 风味色板(Body) + 花纹遮罩(Swirl 形状) × 风味色(Swirl)
         + [纯种配件] + [招牌部件] + [头饰 Topper] + [帽子] + 表情层 + [闪光层] + [P1 形态参数]
```

| 环节 | 方法 | 产出 |
|---|---|---|
| 1. 基础 | 画 1 个灰度身体（含高光/暗部分层）+ 网格 | 所有品种共用 |
| 2. 调色 | 着色器读取色板（4 色）重映射灰度 | 新风味只需 1 套色板 |
| 3. 花纹 | 灰度遮罩在身体 UV 上采样，着 Swirl 风味色 | 新风味只需 1 张遮罩 |
| 4. 叠加层 | 配件、头饰、帽子用统一锚点（头顶、额头、侧面 3 个锚点/轮廓） | 每件只画 1 次 |
| 5. 预览工具 | 编辑器内“品种拼装预览”：选 Body/Swirl/Topper/Hat 即看效果，并批量导出 64px 缩略图供图鉴 | 美术自检与图鉴图 |
| 6. 校验 | 自动生成全部 29 品种 × 12 帽子的拼图截图，人工过一遍穿模 | 质量检查 |

**单个新风味的内容成本（估算）**：色板 0.5 天、花纹遮罩 0.5 天、纯种配件 0.5 天、食物+原料图标 0.5 天、1～2 个甜品图标 0.5 天 ≈ 2.5 美术日；自动新增 2N+1 个品种。

## 10.4 让新品种“不只是换颜色”

| 手段 | 说明 | 成本 |
|---|---|---|
| 花纹形状差异 | 点、漩涡、碎屑、条纹，形状语言各不相同 | 每风味 1 张遮罩 |
| 材质差异 | Sugar 透明、Cream 哑光、Cocoa 厚重等（10.1） | 着色器参数 |
| 形变手感差异 | Cocoa 回弹慢 15%、压缩幅度小；Lemon 回弹快 10%；Pure 更“满” | 参数 |
| 音色差异 | 每个 Body 风味不同音色（08 章） | 音频 |
| 纯种配件 | 4 个 | 小 |
| 招牌轮廓 | 改变剪影（云朵、滴落、蛋糕层、三色带）+ 专属闲置 | 中 |
| 个体差异 | 性格动画权重、头饰、帽子、闪光 | 小 |

## 10.5 2D 形变实现成本评估

| 方案 | 效果 | 程序成本 | 美术成本 | 性能风险（12 只同屏） | 结论 |
|---|---|---|---|---|---|
| A. 变换缩放（Squash & Stretch，弹簧驱动 scaleX/scaleY/偏移） | 整体压扁回弹 | 0.5～1 天 | 无 | 极低 | **P0** |
| B. 顶点着色器局部凹陷（触点 uniform + 衰减半径 + 弹簧强度） | 手指按下处凹陷、周围鼓起 | 2～3 天 | 身体需细分网格（8×8） | 低 | **P0** |
| C. 控制点网格弹簧（5×5 控制点，CPU 弹簧，带邻接约束） | 拖拽拉长、局部晃动更真实 | 5～7 天 + 调参 | 同 B | 中（12 只 × 25 点 × 60fps 可接受，仅当前围栏计算） | **P1**：先用于宠物详情近景单只 |
| D. 软体物理（压力模型/质点弹簧+碰撞） | 史莱姆之间可挤压 | 2～3 周 + 大量调参 | 无 | 高（稳定性、穿透） | **不做** |

P0 组合 A+B 足以支撑“触点凹陷+整体压扁+回弹+拉伸跟手”；长按拉伸用 A 的拉伸轴指向手指方向实现。第 0～2 周的触感原型（12 章 M0）就是为了验证 A+B 是否达标。

## 10.6 质量标准（美术验收清单）

| # | 检查项 | 标准 |
|---|---|---|
| Q1 | 缩略图可读性 | 64px 下 29 品种两两可区分（10 人内测，正确率 ≥90%，实验目标） |
| Q2 | 色弱 | Deuteranopia/Protanopia 模拟下，同 Body 不同 Swirl 可区分 |
| Q3 | 形变不穿帮 | 最大压缩/拉伸时花纹、配件、帽子不分离、不出现锯齿缝 |
| Q4 | 锚点 | 12 顶帽子 × 5 种轮廓无穿模 |
| Q5 | 色板对比 | 花纹色与主体色亮度差 ≥15%（Sugar 底除外，使用描边强调） |
| Q6 | 资源规格 | 图集 ≤2048×2048，ASTC 压缩；单个角色部件 ≤512px 源 |
| Q7 | 命名 | `sp_{body}_{swirl}`、`hat_{id}`、`topper_{dessert}`，与配置表 ID 一致 |
| Q8 | 动画帧率 | 程序化动画 60fps；帧动画 ≤12fps 并插值 |
| Q9 | 音频 | 峰值 −1 dBFS，触摸音 ≤250ms，循环音乐无缝 |
