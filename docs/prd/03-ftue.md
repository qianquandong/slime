# 03 · 前3分钟体验与经济交接

> v0.2：首次孵化目标≤3分钟。两周原型采用本章核心流程；Treat测试使用第14章独立夹具。原教学10分钟流程停止使用。

## 3.1 目标与固定快照

| 目标 | 要求 |
|---|---|
| 触摸 | ≤15秒可以摸；拥抱为可选操作，不阻挡进度 |
| 喂食显色 | ≤75秒看懂同食物3次显色；3次可连续点喂 |
| 首次培育 | ≤2分钟开始、≤3分钟孵化；等待30秒时可自由摸 |
| 经营教学 | 第一单只教一次Bake & Deliver；设施、每日任务、权限说明延后 |
| 自主探索 | 不指定第二个配方，不自动填槽；教学完成后可退出或自行继续 |
| FTUE正式结束快照 | L2、30/80 XP、**90金币**、4星星糖、1勺；Sugar 0 / Jam 7 / Cream 9；Mochi/Puff/Berry各60分钟饭碗；图鉴2/29（原型2/11） |

该快照在一次性Starter bowls事务提交后保存；`worked_path()`和经济回归从这个实际状态开始，不得使用“150金币且空碗”作为教学完成状态。固定快照适用于无额外自由触摸产出、无额外喂食的标准路径；玩家额外所得单独累加。FTUE耗时不同造成的正常产出以实际时钟结算，经济夹具以事务刚完成为t=0。

## 3.2 分段脚本

| 时间目标 | 玩家操作与反馈 | 经济状态 |
|---|---|---|
| 0:00–0:20 | Mochi可立即触摸，8次挤出1个Sugar；可长按拥抱；`TUT_01`～`TUT_04`简短分步出现 | 初始50金币，Sugar+1 |
| 0:20–0:50 | 喂Mochi免费Strawberry×3，显示1/3→3/3；Puff到来，默认名可稍后改 | 新手前3草莓免费，每份消化10秒 |
| 0:50–1:15 | 喂Puff免费Milk×3；消费完前6份后结束加速消化；完成Bella的Berry Jelly×1 | Jam9−2=7；Cream9；Sugar1−1=0；金币+20、XP+10 |
| 1:15–1:50 | Bella展示“pink … creamy swirls”；玩家把两只放入Body/Swirl，预览验证；用Swap自行纠正 | 首次Start免费；不消耗亲本；30秒计时 |
| 1:50–2:30 | 可自由摸或看简单图鉴；荚完成后玩家点击孵化Berry，再Show给Bella | 首次发现+30XP/+1星星糖；L2奖励50金币/+1星星糖/+1勺；Show奖励30金币/+10XP；此时150金币、30/80XP、4星星糖 |
| 2:30–3:00 | `TUT_STARTER_BOWLS`显示60金币；一次性装入Mochi方糖×6、Puff牛奶×4、Berry草莓×4。显示`TUT_STARTER_LEFT`；`TUT_19`中性邀请自由探索 | 150−(12+24+24)=**90金币**；各60分钟饭碗。Mochi显色Sugar、Puff显色Cream、Berry显色Strawberry |

Starter bowls是明确的一次性60分钟装填，**不是**正常Refill All（L1上限120分钟）。正常Refill All在自由阶段提供；如果玩家自行选择用完金币，显示费用与剩余金额，不静默代替选择。Starter事务不可重领，失败或杀进程必须整体重放或整体回滚。

## 3.3 下一次自主培育的资源保证

三只现有表达风味可覆盖全部3×3普通组合中的异风味组合；同风味结果需要先把两只调成同一风味。最便宜的未发现异风味结果费用40（如Cream Slime），已有匹配亲本无需再喂，90−40=50金币。第二次计时≤2分钟，第三次≤5分钟；只缩短时间，不额外免除费用或赠送奖励。测试者不被提示选择Cream Slime，脚本仅用它作确定性经济回归。

正常加满饭碗花费120并剩30金币的旧路径不再作为教学步骤。第二次自主培育结束前不提示买Pantry Shelf，不弹通知权限或商店。所有自主指标排除脚本Start、自动填槽、每日任务推荐与主持人提示。

## 3.4 异常与恢复

| 情况 | 处理 |
|---|---|
| 放反Body/Swirl | 保留预览并提示Swap，允许坚持开始；得到对称品种后提供一次免费纠正。纠正不计“自主第二次”，另记`ftue_repair`；其发现奖励仍按首次规则实际发放，不能硬重置成固定快照 |
| 拖动失败 | 第二次失败显示点选替代；不扣费 |
| 离开/强退 | 按已提交步骤恢复，计时真实推进；Starter bowls和发现奖励各只发一次 |
| 超时/不想继续 | 不强制留在场景；测量实际耗时与退出位置，不自动算作完成 |
| 无网络 | 核心教学可完成；两周原型无联网SDK |
| 满碗想换色 | 引导已有Swap Snack退回未开始的食物后，喂所需3份；已消化中的食物不退款（06章） |

后续真实时间测试再验证L3解锁、生产覆盖和回访；本章的3分钟目标是待验证的设计标准。
