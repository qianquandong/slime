# 08 · UI 与互动表现

## 8.1 布局原则（竖屏单手）

| 原则 | 要求 |
|---|---|
| 拇指区 | 高频操作（Refill All、食物托盘、Bake & Deliver、Start、Hatch）放在屏幕下 40%；顶部只放信息 |
| 触摸目标 | 按钮 ≥44×44pt；史莱姆碰撞体 ≥88×88pt；底部 34pt（Home 指示条）内不放控件 |
| 层级 | 场景（牧场）→ 底部弹出面板（Sheet，可下滑关闭）→ 全屏页（图鉴、商店）→ 系统弹窗（仅购买、权限） |
| 文本 | 英文；正文 ≥15pt，按钮 ≥17pt，支持 iOS 动态字体到 “Large”（更大时按钮文字缩放最多到 0.85 再截断） |
| 颜色 | 风味不只用颜色区分：花纹形状、图标、文字标签同时存在（色弱可用） |
| 适配 | 基准 iPhone 15（393×852pt）；最小 iPhone SE 3（375×667pt）需完整可用；安全区内布局 |

## 8.3 一只与多只史莱姆时的操作区别

| 方面 | 1 只（新手前段） | 2～4 只（一个围栏） | 5～12 只（多围栏） |
|---|---|---|---|
| 镜头 | 近景，史莱姆占屏宽 45% | 中景，每只约屏宽 22% | 同中景，左右滑切换围栏 |
| 触摸目标 | 整个史莱姆 | 每只碰撞体 ≥88pt；重叠时上层优先，被点者置顶 1 秒 | 同左 |
| 信息 | 常驻显示 | 点哪只显示哪只的气泡（3 秒后淡出） | 围栏标题显示最短饭碗剩余 |
| 喂食 | 拖食物 | 拖食物；或“先点食物再连续点多只” | 同左 + Refill All（只加满当前围栏）/ 长按 Refill All = 全部围栏 |
| 培育选亲本 | — | 拖到窝 / Nest 页列表 | Nest 页列表，可按表达风味筛选 |
| 性能 | — | 4 只全动画 | 只有当前围栏播放动画；相邻围栏渲染静帧（供滑动预览）；其余围栏不渲染 |

## 8.4 触摸反馈分层

| 层 | 时间窗 | 内容 | 实现建议 | 可关闭项 |
|---|---|---|---|---|
| L1 即时 | 0～16.7ms（同帧） | 触点处局部凹陷（着色器 dent：触点坐标+强度）；触点涟漪 | 顶点着色器，uniform 传触点；无需等待动画系统 | Reduce Motion 下凹陷幅度 50% |
| L2 形变 | 0～120ms | 压扁：Y 0.86～0.92、X 1.06～1.10（保持面积近似），中心下移 | 弹簧 Squash：刚度 k=280、阻尼比 ζ=0.38（初始设计值，原型调） | — |
| L3 回弹 | 120～500ms | 欠阻尼回弹 1～2 次过冲（最大 6%），表情切换 | 同一弹簧系统 | Reduce Motion：ζ=0.7 无过冲 |
| L4 声音 | 同 L1 帧触发 | 按 Body 风味选音色；音高=性格偏移+连点阶梯+随机 ±0.5 半音；音量随点击间隔（越快越轻，防刺耳） | 每音色 3 个变体轮换，避免重复感 | Sounds 开关 |
| L5 震动 | 同 L1 帧 | 抚摸：轻（light impact）；挤出原料：中（medium）；拥抱：柔（soft）连续 2 下；发现新品种：success 通知型 | UIImpactFeedbackGenerator / UINotificationFeedbackGenerator；预热 prepare() | Haptics 开关 |
| L6 结果 | 300ms～2s | 爱心粒子（仅计分时）、挤一挤环、原料弹出、情绪 | 粒子池复用 | — |
| L7 长期 | 升级时 | 亲密升级横幅、新互动解锁 | — | — |

**动画时长建议**

| 动画 | 时长 | 备注 |
|---|---|---|
| 抚摸形变+回弹 | 350～500ms | 可被下一次点击打断并叠加（取最大压缩） |
| 狂点晕眩 | 2.5s | — |
| 长按拉伸 | 跟手；松手回弹 450ms | — |
| 拥抱 | 1.0s 触发后爱心 0.8s | — |
| 喂食咀嚼 | 600ms | 连续喂食可排队，最多 3 个排队后加速至 300ms |
| 染色转场 | 400ms | — |
| 原料弹出→飞入罐 | 300ms 弹出 + 600ms 飞行 | 批量时合并为 1 个“+N”飞行 |
| 烘焙 | 1.0s | Deliver All 时合并为 1.2s |
| 孵化揭晓 | 2.5s（0.8s 后可点跳过） | 招牌 3.5s |
| 升级 | 1.5s | — |
| 页面切换 | 250ms | Reduce Motion：淡入淡出 150ms |

**声音变化规则**

| 维度 | 规则 |
|---|---|
| 音色 | Sugar：玻璃质 squeak；Strawberry：清脆 pop；Cream：闷软 squish；Lemon：轻快 chirp；Cocoa：低沉 gloop；招牌使用其 Body 音色+专属尾音 |
| 性格音高偏移 | Bouncy +2、Curious +1、Cheeky +1、Gentle 0、Shy −1、Sleepy −2（半音） |
| 连点阶梯 | 每次 +0.5 半音，最多 +3，停 1.5s 归零 |
| 体型 | Pure 与招牌 −1 半音（更“厚重”） |
| 晕眩 | 下行滑音 |
| 混音 | 同时最多 6 个史莱姆音源；超出时丢弃最旧的 |

## 8.5 误触保护

| 风险操作 | 保护 |
|---|---|
| 内购 | 只走 iOS 系统购买弹窗；商店内单击只打开详情，详情页再点价格按钮 |
| 花费 ≥300 金币的 Refill All | 二次确认 `REFILL_CONFIRM`（可在设置中关闭） |
| 花费星星糖（提示、护符、设施、帽子） | 二次确认 |
| 设施升级 | 二次确认，显示前后效果 |
| 放生 | 长按 1 秒确认（`REHOME_HOLD`）；收藏锁的不可放生；最后一只同品种额外提示 |
| 中止培育 | 二次确认（费用、Treat 不退） |
| 喂错食物 | 3 秒内 Undo，退金币、恢复连喂进度 |
| 切围栏时误拖史莱姆 | 起点在史莱姆上=拖拽，不切页；切页需从空地滑动 |
| 柜台出售 | 显示“Orders pay more!” 并二次确认 |
| 广告按钮 | 与主按钮间距 ≥16pt；不放在 Refill All/Start 等高频位置 |

## 8.6 减少重复操作

| 重复点 | 方案 |
|---|---|
| 逐只喂食 | Refill All（当前围栏）/ 长按 = 全部围栏；Fill Up 一次喂满 |
| 逐个烘焙再交付 | Bake & Deliver；Deliver All |
| 收原料 | 自动入罐，无需点击收集 |
| 重复同一组合培育 | Repeat Last |
| 找可做的品种 | 图鉴 Breed This 自动预填亲本 |
| 批量放生 | 小屋多选模式 `Select to rehome` |
| 新史莱姆安置 | 自动放入有空位的围栏，否则小屋 |
| 回来查看 | 离线结算一屏看完；通知只在孵化完成、全部空碗（每天最多 1 条）、新访客时发送 |
