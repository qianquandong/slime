# 00 · 总览、假设与术语

> 版本：v0.1 评审稿 · 日期：2026-10-11 · 读者：程序、2D美术、策划/测试
> 数值状态：**全部为初始设计值**，以 `config/*.csv` 为唯一数据源；`python tools/balance_check.py` 可复算本文所有公式、算例与闭合检查。

## 0.1 一句话定义

竖屏、单手操作的 iPhone 宠物养成游戏：玩家揉捏有名字和性格的史莱姆，喂不同食物让它显色，把两只史莱姆放进培育窝的 **Body / Swirl** 两个槽位，按**看得见的规则**培育出新品种；史莱姆消化食物产出甜品原料，玩家做甜品、交订单，用收入扩建牧场、继续培育。

## 0.2 关键决策摘要（评审时优先确认）

| # | 决策 | 理由 | 所在章节 |
|---|---|---|---|
| D1 | 培育结果的**品种完全确定**：Body槽亲本的表达风味 → 主体颜色；Swirl槽亲本的表达风味 → 花纹；Treat槽甜品 → 头饰，并可能触发招牌品种 | 满足“可观察、可推理、可验证”；随机只用于名字、性格、最爱食物、闪光 | 05 |
| D2 | “食材影响风味和颜色”进 P0（以“连喂3次表达风味”的形式）；“环境影响质感/形态”放 P1；“品种生产协作”放 P2 | P0 用两条轴（主体×花纹）+ 招牌配方已足够验证核心假设；第三条轴会让组合和美术量翻倍 | 05 |
| D3 | 图鉴 = 风味矩阵（N×N）+ 招牌品种；形态、头饰、闪光作为“印章/个体属性”，**不扩充图鉴格数** | 控制组合爆炸：P0 共 25+4=29 个品种，P1 加1种风味也只到 36+5 | 05 |
| D4 | 烘焙**即时完成**（1秒动画），不设烤箱队列 | 3人团队少做一个计时系统；2～5分钟短局里每次打开都能完成交付 | 06 |
| D5 | 每种原料**独立上限**（不是共享仓库） | 防止“仓库被单一原料塞满→全线停产”的死锁 | 06/07 |
| D6 | 柜台直接出售甜品只给 0.4×价格、不给经验；订单给 1.25×价格+经验 | 让订单成为金币与经验的主引擎，柜台只当溢出阀 | 07 |
| D7 | 不设付费货币；商品直接标价，全部可预览；**MVP 不使用付费随机** | 3人团队可维护；降低合规与信任风险 | 09 |
| D8 | MVP 无账号、无自建服务端；本地存档+系统备份；云存档 P1 | 成本与排期；单机内容无竞技公平问题 | 11 |
| D9 | 首测地区建议英语市场（先菲律宾/马来西亚测技术与留存，再加拿大/澳大利亚/新西兰测付费），**暂不进入中国大陆** | 玩家可见文本全英文；大陆上线需版号与防沉迷实名接入，超出 MVP 范围 | 01 |
| D10 | 12 周只够做垂直切片；16 周交付留存验证版需砍掉第 1、2 档内容且风险高；计划基线为 W18 软启动 1（无商业化）、W22 软启动 2（含商业化） | 单程序估算：P0 86～110 人日 + 商业化 9～11 人日（16 周 = 80 人日） | 12 |

## 0.4 术语表（中文文档用语 ↔ 游戏内英文）

| 文档用语 | 游戏内英文 | 定义 |
|---|---|---|
| 风味 | Flavor | 5 种（P0）：Sugar（原味）、Strawberry、Cream、Lemon、Cocoa；决定颜色、花纹样式、产出原料 |
| 食物 / 饲料 | Snack（Sugar Cube / Strawberry / Milk / Lemon / Cocoa Bean） | 用金币购买并喂给史莱姆；每种食物对应一种风味 |
| 原料 | Goodies（Sugar / Berry Jam / Fresh Cream / Lemon Curd / Cocoa） | 史莱姆消化食物后产出，进储藏罐 |
| 甜品 | Dessert | 由原料即时烘焙，用于订单、柜台出售或作为培育 Treat |
| 饭碗 / 饱食 | Bowl | 以“剩余消化分钟”计；空了史莱姆就睡觉、停产，不受惩罚 |
| 表达风味 | Showing: {flavor} | 史莱姆当前显出的风味；连续喂同一食物 3 次后切换；培育时读取它 |
| 主体 / 花纹 / 头饰 | Body / Swirl(Pattern) / Topper | 品种外观三层；头饰是个体出生属性，不是品种 |
| 招牌品种 | Signature | 特定 Body+Swirl+Treat 组合得到的专属造型品种（P0 共 4 个） |
| 培育窝 / 孵化荚 | Nest / Pod | 培育在窝中进行，结束后点荚孵化 |
| 亲密 | Friendship | 0～5 级，靠抚摸、拥抱、喂食累积；不衰减 |
| 星星糖 | Star Sugar | 稀有资源：解锁提示、部分高级设施 |
| 加速勺 | Speed Spoon | 每把减少 30 分钟培育时间；只作用于培育 |
| 访客请求 / 探索订单 | Visitor Request | 访客描述想看的外观，玩家带去符合的史莱姆（不消耗） |
| 小屋 | Nap House | 存放不在围栏里的史莱姆；不产出、不需要照料 |
| 图鉴 | Slime Book | 风味矩阵 + 招牌页 |
