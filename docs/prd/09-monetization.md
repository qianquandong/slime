# 09 · 商业化

## 9.1 原则

| 原则 | 规则 |
|---|---|
| 确定商品优先 | 每个商品在购买前可预览（Preview / Try On 在自己的史莱姆上试穿），买到什么就是什么 |
| 不卖主线 | 品种、配方提示答案、星星糖、等级不出售；主线全部可免费完成（06 章 6.9） |
| 无付费货币 | 商品直接以 App Store 价格标价，避免“汇率”与过期问题（Apple 3.1.1：内购货币不得过期） |
| MVP 不使用付费随机 | 见 9.7 |
| 广告完全自愿 | 只有激励视频，无插屏、无横幅；不看广告也能获得全部内容 |
| 不在情绪高点打断 | FTUE、孵化揭晓、升级演出期间不出现任何购买提示 |

## 9.4 展示时机总规则

| 规则 | 说明 |
|---|---|
| 首日 | 不出现任何情境购买推荐；商店入口可见 |
| 情境推荐频率 | 全部情境横幅合计每天最多 1 次；被关闭（Not now）后该商品 7 天内不再情境推荐 |
| 禁止时机 | FTUE、孵化揭晓、升级演出、离线结算弹窗、任何二次确认弹窗之上 |
| 年龄 | 中性年龄门判定 <13 岁：不显示情境推荐；广告请求标记儿童导向；不弹 ATT；购买仍走 Apple 家长控制（Ask to Buy → `SHOP_PENDING`） |
| 离线 | 商店显示 `SHOP_OFFLINE`，不显示价格 |

## 9.6 月度/赛季内容与小团队可持续性

| 节奏 | 每期所需内容 | 美术 | 策划 | 程序 | 占 3 人团队产能 | 结论 |
|---|---|---|---|---|---|---|
| 每月（4 周） | 1 主题色调+2 装饰、8 件外观、1 个新招牌配方（免费）、1 组活动订单、约 20 条文案 | 8～10 天 | 3 天 | 2～3 天（配置驱动） | 美术约 45%，会挤占 P1 功能 | **不建议** |
| 每 6 周 | 同上 | 8～10 天 | 3 天 | 2～3 天 | 美术约 30% | 软启动验证 D30 后可试 |
| 每 8 周 | 同上 | 8～10 天 | 3 天 | 2～3 天 | 美术约 22% | **建议首选** |

前置条件：外观、招牌配方、活动订单全部由配置表驱动（11 章字段），无需发版即可上线新赛季素材（素材随版本预埋或按需下载资源包——资源包下载为 P2）。

## 9.7 关于付费随机机制

**MVP 不使用**任何付费随机（盲盒帽子、随机培育结果、随机加速等）。理由：① 与“可推理、可验证”的产品支柱冲突；② 确定商品已能覆盖装扮需求；③ 小团队难以维护概率公示与保底的合规成本。

若未来提出“神秘帽子盒（Mystery Hat Box）”之类机制，上线前必须满足：

| 项 | 要求 |
|---|---|
| 必要性论证 | 证明确定商品的购买转化已饱和，且随机机制带来的是“收集惊喜”而非“抽到为止” |
| 概率公示 | 购买前公示每一件物品的概率（Apple App Review Guideline 3.1.1） |
| 保底 | 每 N 次（如 6 次）必出未拥有物品；集齐后不再出售 |
| 重复处理 | 重复物品按购买价等值转换为可选的确定商品兑换点 |
| 未成年人 | <13 岁不可购买（中性年龄门） |
